==================================================
1. PURPOSE
==================================================

목표:
1) BTC 장기 상승 추세 수익을 최대한 유지한다.
2) 큰 하락장에서 BTC 목표 노출을 줄여 MDD를 개선한다.
3) 단기·중기 미래 목표가와 지지·저항을 데이터 기반으로 계산한다.
4) 기본 보유분은 최대한 유지하고 전술 비중만 제한적으로 매매한다.
5) 최고 백테스트 수익보다 재현성·단순성·과최적화 방지를 우선한다.

운영 철학:
Observation → Evidence → Interpretation → Validation → Action

기본 구조:
Core Holding + Tactical Trading


==================================================
2. ENGINE ARCHITECTURE
==================================================

본 엔진은 단일 100점 합산 모델이 아니다.

독립 엔진:
1) Market Regime Engine
2) Statistical Range Engine
3) Price Structure Engine
4) Elliott/Fibonacci Target Engine
5) Derivatives Flow Confirmation Engine

최종 Decision Engine은 각 엔진의 역할별 결과를 종합한다.

모든 데이터를 하나의 Directional Score로 단순 합산하지 않는다.


==================================================
3. MARKET REGIME ENGINE
==================================================

목적:
전체 BTC 목표 노출(Target BTC Exposure)을 결정한다.

사용:
- Daily Close
- EMA50
- EMA150
- EMA200

150EMA와 200EMA를 각각 평가한 뒤 Ensemble(앙상블)한다.

각 Long EMA 기준:

A)
Price > Long EMA
AND EMA50 > Long EMA
→ Exposure 100%

B)
Price > Long EMA
AND EMA50 <= Long EMA
→ Exposure 90%

C)
Price < Long EMA
AND Price > EMA50
→ Exposure 75%

D)
Price < EMA50
→ Exposure 50%

Final Target BTC Exposure
= (150EMA Exposure + 200EMA Exposure) / 2


==================================================
4. REGIME VALIDATION STATUS
==================================================

150EMA 단독은 일부 백테스트에서 가장 높은 성과를 기록했지만,
특정 단일 파라미터 의존 위험을 줄이기 위해 최종 엔진에서는 단독 사용하지 않는다.

150 / 200 / 250 EMA Parameter Sensitivity와 Rolling Window 검증에서
전략 구조가 붕괴하지 않았고, 150/200 Ensemble은 수익성과 안정성의 균형이 양호했다.

정확한 표현:
"현재 검증 결과상 가장 견고한 Core Regime 후보"

금지 표현:
"절대적 최적전략"
"항상 Hold를 상회"

검증 요약:
- 일부 장기 고정구간에서는 BTC Hold 상회
- Walk-forward에서는 Hold 수익의 약 91%를 유지하면서 MDD 개선


==================================================
5. POSITION DEFINITIONS
==================================================

용어를 다음처럼 고정한다.

Target BTC Exposure:
Market Regime Engine이 결정한 전체 BTC 목표 노출.

Core Sleeve:
Target BTC Exposure 중 기본 보유분.

Tactical Sleeve:
Target BTC Exposure 안에서만 운용하는 전술 비중.

Core와 Tactical은 별도로 더하지 않는다.

항상:
Core Sleeve + Tactical Sleeve <= Target BTC Exposure

Tactical Sleeve 최대:
min(전체 자산의 20%, Target BTC Exposure의 20%)

예:
Target Exposure 100%
→ Tactical 최대 20%
→ Core 최소 80%

Target Exposure 70%
→ Tactical 최대 14%
→ Core 최소 56%

별도 레버리지 추가 금지.


==================================================
6. STATISTICAL RANGE ENGINE
==================================================

목적:
현재 BTC가 특정 기간 안에 현실적으로 움직일 수 있는 가격 범위를 계산한다.

사용 데이터:
- Historical OHLCV
- ATR14
- Historical MFE
- Historical MAE
- 현재와 유사한 과거 가격·변동성 구조

MFE:
Maximum Favorable Excursion

MAE:
Maximum Adverse Excursion

시간축:
Ultra Short: 6H / 12H / 24H / 48H
Short: 5D / 10D
Medium: 30D / 60D / 90D

출력:
- MFE P50 / P70 / P80 / P90
- MAE P50 / P70 / P80

중요:
MFE/MAE와 ATR은 서로 독립 신호로 이중 계산하지 않는다.

Statistical Range Signal
= MFE/MAE + ATR Normalization을 하나의 통합 통계 신호로 취급한다.

검증:
5일 MFE/ATR 중앙값은 여러 기간에서 약 0.9~1.05 ATR,
P80은 약 1.5~1.6 ATR 범위에서 비교적 안정적이었다.


==================================================
7. PRICE STRUCTURE ENGINE
==================================================

목적:
실제 시장이 반응했던 구조적 지지·저항을 찾는다.

시간축:
15m / 1H / 4H / 1D / 1W 보조

사용:
- Previous High / Low
- Swing High / Low
- Breakout / Retest
- Multi-Timeframe Confluence
- OHLCV Volume

강한 Resistance:
과거 고점 + 반복 테스트 + 거래량 + 다중 시간대 중첩

강한 Support:
과거 저점 + Breakout Retest + 다중 시간대 중첩

OHLCV Volume은 Price Structure Engine에 포함한다.

Taker Buy/Sell은 별도 Derivatives Flow Engine에서만 사용한다.


==================================================
8. ELLIOTT WAVE + FIBONACCI ENGINE
==================================================

목적:
미래 Target Cluster와 중기 확장 목표를 계산한다.

Core Exposure를 직접 변경하지 않는다.

역할:
- Current Wave
- Wave 3 / Wave 5 Target
- Extension Target
- Retracement Support
- Invalidation
- 1~3개월 미래 목표가

Fib Retracement:
0.382 / 0.500 / 0.618

Fib Extension:
1.000 / 1.272 / 1.618 / 2.000

Anchor 규칙:
A = 시작점
B = 상승/하락 끝점
C = 조정점
또는 명확한 Swing Low / Swing High 사용

Anchor가 불명확한 Fib 목표는 공식 Target으로 사용하지 않는다.

Invalidation:
모든 Elliott 분석에는 반드시 무효화 가격을 표시한다.
Invalidation 이탈 시 기존 Count를 유지하지 않고 재분석한다.


==================================================
9. TARGET CLUSTER RULE
==================================================

목표가는 하나의 지표만으로 결정하지 않는다.

Target 구성 요소:
1) Statistical Range
2) Price Structure
3) Elliott Wave Target
4) Fibonacci Extension
5) Derivatives/Flow Confirmation

Main Target Cluster 승격 조건:

필수 조건:
- Statistical Range 또는 Price Structure 중 최소 1개 반드시 포함

추가 조건:
- Elliott / Fibonacci / Flow / 나머지 핵심 구조 중 2개 이상 추가 중첩

즉,
"아무 신호 3개" 단순 카운트는 금지한다.

MFE와 ATR은 Statistical Range 하나로 계산하므로
두 개 독립 신호로 중복 카운트하지 않는다.

Target 등급:
Base Target
Main Target
Extension Target

활성화 순서:
Base → Main → Extension


==================================================
10. DERIVATIVES FLOW CONFIRMATION ENGINE
==================================================

목적:
목표가 자체를 생성하지 않고 현재 움직임의 Quality를 평가한다.

우선순위:
1) Open Interest
2) Global Long/Short
3) Basis
4) Premium Index
5) Spot/Futures Spread
6) Funding
7) Taker Buy/Sell
8) Top Trader Position

데이터 제한:
- OI / L/S / Top Trader / Taker: 최근 약 31일 중심
- Basis: 상대적으로 장기
- Funding: 수개월 수준
- OHLCV: 장기 가능

따라서 파생데이터는 Long-term Core Predictor가 아니라
Current Confirmation Layer로 사용한다.

해석 예:

Healthy Bullish Expansion:
Price 상승
+ OI 완만한 증가
+ Taker Buy 우위
+ Funding 낮거나 중립
+ Basis 과열 없음
+ Global L/S 과도한 Long 아님

Leveraged Overheating:
Price 상승
+ OI 급등
+ Funding 급등
+ Global L/S Long 극단

Top Trader Position 단독 매수신호 금지.
Taker 단독 매수/매도신호 금지.


==================================================
11. TACTICAL EXECUTION RULE v1.0
==================================================

Tactical Trading은 검증 완료 Core Engine과 분리 관리한다.

아직 완전히 장기 검증된 Alpha Engine으로 간주하지 않는다.

Tactical Sleeve는 Section 5의 한도를 초과할 수 없다.


==================================================
12. TACTICAL SELL
==================================================

검토 조건:
- Main Target Cluster 접근
- Statistical Range 상단
- 주요 Resistance
- Elliott/Fib 중첩
- 가격 상승 대비 OI/Volume 약화
- Taker 약화
- Funding/Basis 과열

실행 후보:
Section 9의 Target Cluster 조건을 충족하면서
Flow가 악화 또는 과열을 보일 때 Tactical Sell 우선 검토.

기본 분할:
30% / 40% / 30%

주의:
이 비율은 Tactical Default이며 절대 규칙이 아니다.

Core Sleeve는 Elliott/Fib Target 도달만으로 자동매도하지 않는다.


==================================================
13. TACTICAL BUY
==================================================

추격매수 금지.

매수 후보:
- Support Cluster
- Statistical Downside Range(MAE/ATR)
- Fib Retracement
- 가격 안정화 / Retest

기본 분할:
25% / 40% / 35%

주의:
이 비율 역시 Tactical Default이며 추가 검증 대상이다.


==================================================
14. BREAKOUT CONFIRMATION
==================================================

Resistance 돌파는 가격 한 번의 터치만으로 확정하지 않는다.

확인 요소:
1) 1H 또는 4H 종가 돌파
2) OHLCV Volume 증가
3) OI 정상 증가
4) Taker Buy 우위
5) Funding 과열 없음

판정:
3개 이상 충족 → Confirmed Breakout 후보
2개 이하 → False Breakout 가능성 경고

주의:
이 규칙은 Tactical Execution v1.0이며 장기 검증 완료 Core Rule이 아니다.

22. FINAL OPERATING PRINCIPLES
==================================================

가격을 먼저 본다.
시장국면을 먼저 판단한다.
Regime이 Target BTC Exposure를 결정한다.
Statistical Range가 현실적인 이동폭을 계산한다.
Price Structure가 실제 지지·저항을 정의한다.
Elliott/Fibonacci가 미래 목표를 계산한다.
Derivatives Flow가 현재 움직임의 질을 확인한다.

Core Sleeve는 Elliott/Fib 목표 도달만으로 매도하지 않는다.
Tactical Sleeve만 제한적으로 분할매매한다.

추격매수 금지.
상승 시 분할매도.
조정 시 분할매수.
틀린 Elliott Count는 즉시 폐기한다.

과최적화된 최고 수익보다
여러 시장국면에서 살아남는 단순하고 재현 가능한 규칙을 우선한다.
